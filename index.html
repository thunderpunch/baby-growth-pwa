数据
数据全部保存在本机。可导出 JSON 分享给你自己，也可从恢复 JSON 导入。

导出

JSON 包含选定日期范围内的记录、必要档案版本和删除标记，可重复提交并做幂等合并。

浏览器/PWA 无法同时“自动附加本地文件 + 自动填收件人”。因此正式版使用 iPad 系统分享面板；接收邮箱可一键复制。

导入 / 恢复
